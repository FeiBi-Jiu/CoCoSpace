# M1 #10 · 战争迷雾遮罩

## 所属阶段
M1 · 能玩

## 任务目标
MVP 客户端版战争迷雾：按点亮区域画黑，不做可见性过滤，二期升级为服务端可见性判定。

## 前置依赖
- 前端：地图渲染（M1 #9）
- 后端：据点点亮状态同步（B1）

## 已有骨架
- `Assets/Scripts/Map/FogOfWarMVP.cs` — 迷雾 MVP 实现

## 实现步骤

### 1. MVP 方案（客户端版）
- 一张全屏 RenderTexture 或 UI Image 作为遮罩
- 已探索区域 = 透明，未探索区域 = 黑色
- 用 `Texture2D.SetPixel` 或 Shader 实现圆形/扇形透明区域

### 2. 点亮规则
- 玩家进入据点 → 该据点区域点亮（变透明）
- 道路连接的据点 → 玩家走过的道路点亮
- 点亮是持久的（已探索区域保持可见，只是变暗表示"已探索但当前不可见"）
- 灰盒阶段不做"当前可见"与"已探索"的区分，全亮即可

### 3. 实现方式
**方案 A：Shader 遮罩（推荐）**
- 全屏四边形 + Shader
- Shader 接收"点亮中心列表"（据点坐标 + 半径）
- 片元着色器计算到各点亮中心的距离，在半径内透明，否则黑色
- 性能好，支持任意数量点亮区域

**方案 B：RenderTexture 烘焙（简单）**
- 开局生成一张与地图同尺寸的 `Texture2D`
- 每帧把玩家周围区域擦黑（`SetPixel` 透明）
- 适合据点数量少、地图小的灰盒

### 4. 同步
- 据点点亮状态由服务器同步（玩家进入据点时服务器广播 `S2C_NodeExplored`）
- 客户端收到后更新点亮列表
- 灰盒阶段可简化为：客户端本地检测玩家进入据点就点亮，不依赖服务器

## 与后端对接
| 方向 | 消息 | 说明 |
|---|---|---|
| S→C | `S2C_NodeExplored`（可选） | 据点被探索，点亮该区域 |
| 或 | 快照中据点状态字段 | 据点 `explored` 标志 |

## 关键技术点
- **MVP 不做可见性过滤**：不判断"墙后是否可见"，只判断"是否到过"
- **二期升级**：服务端做视野判定（考虑遮挡），下发"可见实体列表"，客户端只渲染可见的
- **性能**：用 Shader 而非每帧 `SetPixel`，后者在大地图上很慢
- **灰盒够用**：只要能区分"去过/没去过"即可，不追求写实迷雾

## 验收标准
- [ ] 未探索区域显示黑色遮罩
- [ ] 玩家进入据点后，该据点区域变透明
- [ ] 已探索区域保持可见（不全黑）
- [ ] 帧率不受迷雾影响
