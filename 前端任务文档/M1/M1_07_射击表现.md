# M1 #7 · 射击表现

## 所属阶段
M1 · 能玩

## 任务目标
自己开火立刻出弹（本地预测渲染），命中判定在服务器，客户端预测命中只做即时特效，被服务器否决则收回。

## 前置依赖
- 前端：上行状态发送（M0 #4）、弹幕系统（M1 #8）
- 后端：命中判定 + 伤害结算（B1 #9）

## 已有骨架
- `Assets/Scripts/Combat/FirePrediction.cs` — 开火预测与命中表现
- `Assets/Scripts/Combat/BulletPool.cs` — 子弹对象池
- `Assets/Scripts/Net/IntentSender.cs` — 开火意图上报

## 实现步骤

### 1. 开火流程
```
按下鼠标左键
  ├─ 本地预测：Instantiate(muzzlePrefab)  // 枪口特效立刻出
  ├─ 本地预测：从子弹池生成子弹飞向目标    // 视觉即时反馈
  ├─ 设置 pendingFx[seq] = fx              // 记录待确认特效
  └─ 上报 C2S_Intent.Fire（由 IntentSender 打包）
        └─ FireIntent { x, z, yaw, skill_id }
```
- `FirePrediction.PredictFire(skillId)` 处理本地预测
- 开火意图由 `IntentSender` 按 20Hz 打包上报（灰盒阶段合并到定频包）
- `seq` 序列号关联预测特效与服务器结果

### 2. 命中判定（服务器权威）
- 客户端**不做**命中判定，只做视觉预测
- 服务器收到 `FireIntent` 后做 raycast/碰撞检测，下发 `S2C_HitApply`：
```
S2C_HitApply {
  uint32 attacker_entity_id
  uint32 victim_entity_id
  uint32 damage_dealt
  bool   critical
  // 元素附着、反射归属等扩展字段
}
```
- `FirePrediction.OnHitApply` 处理服务器结果：
  - 命中 → 播放命中特效 + 伤害数字
  - 未命中（无对应 HitApply）→ 预测子弹飞行到寿命结束自然消失
  - 否决（服务器说没打中，但客户端预测打中了）→ 收回/淡化预测特效

### 3. 预测与权威的关系
| 客户端做 | 服务器做 |
|---|---|
| 枪口闪光特效 | 命中判定 |
| 子弹飞行轨迹（视觉） | 伤害数值 |
| 即时命中特效（预测） | 元素附着/组合 |
| 伤害数字（预测，可被覆盖） | 击杀归属 |
- 客户端预测的伤害数字是"假"的，服务器结果回来后用真实值覆盖
- 灰盒阶段可以简化：不做预测命中特效，只做枪口闪光，等 `S2C_HitApply` 再播命中特效

### 4. 子弹寿命
- 预测子弹有寿命（如 2 秒），超时自动回收到对象池
- 若服务器判定命中，命中特效在目标位置播放，预测子弹可直接销毁
- 若服务器判定未命中，预测子弹继续飞行直到寿命结束

## 与后端对接
| 方向 | 消息 | 说明 |
|---|---|---|
| C→S | `C2S_Intent.Fire` | 开火意图：位置/朝向/技能 ID |
| S→C | `S2C_HitApply` | 命中结果：攻击者/受害者/伤害/暴击 |
| S→C | `S2C_EntityDeath`（可选） | 实体死亡通知 |

## 关键技术点
- **预测≠判定**：客户端预测只是让手感即时，最终结果以服务器为准
- **收回机制**：`pendingFx` 字典记录未确认的预测特效，服务器否决时销毁
- **灰盒简化**：可以只做枪口闪光 + 等服务器结果，不做预测子弹，降低复杂度
- **延迟补偿**：后端预留（灰盒不实现），实现后客户端无需改动

## 验收标准
- [ ] 按下开火键立刻有枪口特效，无延迟感
- [ ] 服务器判定命中后，目标位置出现命中特效和伤害数字
- [ ] 服务器判定未命中时，预测子弹飞行到寿命结束消失
- [ ] 客户端不计算任何伤害数值
