# M1 #11 · HUD

## 所属阶段
M1 · 能玩

## 任务目标
实现血条、金币、经验条、技能 CD、队友状态栏等核心 HUD。

## 前置依赖
- 前端：快照插值管线（M0 #3）提供实体状态
- 后端：快照中包含 hp/exp/gold/skill_cd 等字段

## 已有骨架
- `Assets/Scripts/UI/HudPanel.cs` — HUD 面板逻辑

## 实现步骤

### 1. HUD 元素
| 元素 | 数据来源 | 更新方式 |
|---|---|---|
| 血条 | 快照中自己的 `hp` / `max_hp` | 收到快照更新 |
| 金币 | 快照中 `gold` | 收到快照更新 |
| 经验条 | 快照中 `exp` / `exp_to_next` | 收到快照更新 |
| 技能 CD | 快照中 `skill_cd[]` 或技能使用事件 | 收到快照/事件更新 |
| 队友状态栏 | 快照中队友的 `hp` / 状态 | 收到快照更新 |

### 2. 自己的 HUD
- 从 `S2C_Snapshot` 中找到 `EntityId == localEntityId` 的实体
- 取 `hp`, `max_hp`, `gold`, `exp`, `exp_to_next` 更新 UI
- 技能 CD：服务器在技能使用时下发 `S2C_SkillCooldown`，或在快照中带 `skill_cd_remaining`

### 3. 队友状态栏
- 遍历快照中所有 `type == Player` 且 `entity_id != localEntityId` 的实体
- 显示每个队友的头像、血条、状态 buff（鬼魂/复活中/引导中）
- 队友数量上限 4 人，布局固定

### 4. 飘字（可选）
- 受击时 `S2C_HitApply` 触发伤害数字飘字
- 升级时 `S2C_LevelUp` 触发升级特效
- 灰盒阶段可用简单 `TextMeshProUGUI` + DOTween 实现

### 5. UI 更新策略
- 不要每帧更新 UI，只在数据变化时更新（事件驱动）
- 快照频率 20Hz，血条直接用快照值即可，无需插值（血条不是位置）
- 金币/经验变化用动画过渡（数字滚动），更有反馈感

## 与后端对接
| 字段 | 说明 |
|---|---|
| `hp` / `max_hp` | 当前/最大生命值 |
| `gold` | 金币数 |
| `exp` / `exp_to_next` | 当前经验/升级所需经验 |
| `skill_cd_remaining[]` | 各技能剩余 CD |
| `buff_mask` | 状态 buff 位图（鬼魂/引导中/无敌...） |

## 关键技术点
- **数据驱动**：HUD 完全由服务器数据驱动，客户端不计算任何数值
- **事件 + 快照结合**：血条/金币用快照，伤害飘字/升级用事件
- **不插值**：HUD 数值不需要插值，直接用最新值
- **性能**：UI 更新频率低于快照频率，避免 GC
