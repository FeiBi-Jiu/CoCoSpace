# M1 #13 · 受击与死亡表现

## 所属阶段
M1 · 能玩

## 任务目标
玩家受击有反馈，死亡后过渡到鬼魂形态（鬼魂系统详见 M2 #17）。

## 前置依赖
- 前端：HUD（M1 #11）、快照插值（M0 #3）
- 后端：命中判定（B1 #9）、死亡状态同步

## 已有骨架
- `Assets/Scripts/Player/DeathGhostTransition.cs` — 死亡→鬼魂过渡
- `Assets/Scripts/Player/GhostForm.cs` — 鬼魂形态
- `Assets/Scripts/Combat/FirePrediction.cs` — 命中表现

## 实现步骤

### 1. 受击表现
- 收到 `S2C_HitApply`（自己是 victim）→ 触发受击反馈：
  - 屏幕红闪（UI Image 短暂变红）
  - 角色受击动画
  - 伤害飘字
  - 摄像机轻微震动
- 受击不打断移动（灰盒阶段），M2 引导状态机才做受击打断

### 2. 死亡流程
```
收到 S2C_EntityDeath { entity_id, killer_id }
  └─ 是自己 → 播放死亡动画 → 过渡到鬼魂形态
  └─ 是队友 → 队友角色播放死亡动画 → 队友变鬼魂（半透明）
  └─ 是怪 → 怪播放死亡动画 → 掉落物出现 → 销毁
```

### 3. 死亡→鬼魂过渡
`DeathGhostTransition` 处理：
- 死亡动画播放完毕（或 1~2 秒后）
- 角色模型变半透明（`material.color.a = 0.5`）
- 禁用碰撞（`Collider.enabled = false`，但服务器侧鬼魂无碰撞已由后端处理）
- 切换到 `GhostForm` 组件
- 开始显示拴绳范围圈（M2 #17）

### 4. 鬼魂形态（灰盒基础）
- 半透明渲染（`RenderingMode = Fade`，`color.a = 0.4`）
- 无碰撞（玩家可以穿过鬼魂）
- 可以移动（跟随队友）
- 完整鬼魂系统（拴绳/搬运/buff）在 M2 #17

### 5. 摄像机与 UI
- 死亡时摄像机不变（继续跟随鬼魂）
- HUD 显示"你已死亡，等待复活"提示
- 可显示复活倒计时（若有祭坛复活）

## 与后端对接
| 方向 | 消息 | 说明 |
|---|---|---|
| S→C | `S2C_HitApply` | 受击：伤害值、是否暴击 |
| S→C | `S2C_EntityDeath` | 实体死亡：entity_id、killer_id |
| S→C | 快照 `state` | 实体状态（alive/dead/ghost） |

## 关键技术点
- **死亡由服务器判定**：客户端不做死亡判定，收到 `S2C_EntityDeath` 才执行死亡表现
- **鬼魂是服务器规则**：前端只做半透明+无碰撞的视觉表现
- **过渡平滑**：死亡动画→鬼魂的过渡要自然，避免瞬移
- **碰撞一致性**：鬼魂无碰撞必须前后端一致，否则会有"客户端穿过但服务器阻挡"的问题

## 验收标准
- [ ] 受击时有屏幕红闪和伤害飘字
- [ ] 血量归零时播放死亡动画并过渡到半透明鬼魂形态
- [ ] 鬼魂无碰撞，可穿过实体
- [ ] 队友死亡时能看到其变鬼魂
