## 实现步骤

### 1. 移动权威隔离
通过 `IMovementAuthority` 接口解耦：
```csharp
public interface IMovementAuthority
{
    Vector3 Position { get; }
    event Action<Vector3, double> OnServerCorrection; // 灰盒不触发
    void Tick(float dt, Vector2 inputDir);
}
```
- 灰盒：`LocalAuthoritativeMovement` —— 客户端直接控制
- 野排升级：新增 `ServerAuthoritativeMovement` —— 服务器回传位置 + 预测纠偏
- `PlayerController` 只依赖接口，切换实现不牵连其他系统

### 2. 本地移动逻辑
`LocalAuthoritativeMovement.Tick`：
```csharp
Vector3 move = new Vector3(inputDir.x, 0, inputDir.y) * speed;  // speed = 6f
velocity.y = gravity * dt;                                        // gravity = -20f
cc.Move((move + velocity) * dt);                                  // CharacterController
```
- 使用 `CharacterController` 处理碰撞
- 输入轴用 `Input.GetAxisRaw`（无平滑，响应更快）
- 灰盒阶段不做加速/减速曲线，直接满速

### 3. 手感调参（重点）
| 参数 | 灰盒默认 | 说明 |
|---|---|---|
| `speed` | 6 m/s | 移动速度，核心手感 |
| `gravity` | -20 m/s² | 重力，配合跳跃 |
| `jumpHeight` | 待定 | 若有跳跃 |
| 输入响应 | GetAxisRaw | 无平滑，即时响应 |
- 手感调优占 M1 一半工时，需反复试玩微调
- 可加 `acceleration` / `deceleration` 让起步/停下更顺

### 4. 输入采集与上报
`PlayerController.Update`：
```csharp
Vector2 dir = new(Input.GetAxisRaw("Horizontal"), Input.GetAxisRaw("Vertical"));
movement.Tick(Time.deltaTime, dir);
sender.LatestInput.pos = movement.Position;          // 上报坐标
sender.LatestInput.yaw = mainCam.transform.rotation.eulerAngles.y;
sender.LatestInput.firePressed = Input.GetMouseButton(0);
sender.LatestInput.skillId = 1;
```
- 每帧更新 `IntentSender.LatestInput`
- `IntentSender` 以 20Hz 采样上报（详见 M0 #4）
- 上报的是**坐标**，不是输入方向——移动权威在客户端

### 5. 相机跟随
- 第三人称俯视或越肩视角
- 相机 yaw 决定 `LatestInput.yaw`，用于开火方向
- 灰盒阶段可用简单的 `Transform.LookAt` 或 Cinemachine

## 与后端对接
- 上报字段：`move.x`, `move.z`, `move.yaw`（见 `C2S_Intent.MoveIntent`）
- 后端处理：速度上限校验、瞬移检测、撞墙校验 → 钳制后广播
- 灰盒阶段：服务器回传的坐标用于其他玩家看到你，本地玩家不回滚
- 升级路径：服务器发现瞬移时下发 `OnServerCorrection`，本地回滚到服务器位置

## 关键技术点
- **隔离原则**：`IMovementAuthority` 是野排升级的关键，切勿在 `PlayerController` 里写死本地逻辑
- **CharacterController vs Rigidbody**：灰盒用 `CharacterController`（更适合人控），物理交互少时够用
- **坐标上报而非输入上报**：后端不需要知道你按了什么键，只需要知道你在哪
- **手感优先**：速度/加速度/转向灵敏度是核心，多花时间调

## 验收标准
- [ ] WASD 控制角色移动，手感顺滑无顿挫
- [ ] 坐标以 20Hz 上报，其他客户端能看到平滑移动
- [ ] 尝试瞬移（如瞬间移动 10m）被服务器钳制
- [ ] 切换到 `ServerAuthoritativeMovement` 时 `PlayerController` 无需修改
