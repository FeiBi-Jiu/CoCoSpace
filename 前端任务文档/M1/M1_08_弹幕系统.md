# M1 #8 · 弹幕系统

## 所属阶段
M1 · 能玩

## 任务目标
按服务器下发的 pattern 规则本地重建弹幕，使用对象池 + GPU instancing 优化性能，不逐帧接收子弹位置。

## 前置依赖
- 前端：Proto 消息对接（M0 #2）、配置表下发
- 后端：弹幕 pattern 生成与广播（B1 #11）

## 已有骨架
- `Assets/Scripts/Combat/BulletPatternPlayer.cs` — pattern 播放器（ring/fan 两种）
- `Assets/Scripts/Combat/BulletPool.cs` — 子弹对象池
- `Assets/Scripts/Table/Defs.cs` — 配置表定义（含 `BulletPatternDef`）

## 实现步骤

### 1. Pattern 规则格式（与后端对齐）
```
BulletPatternDef {
  string shape        // "ring" | "fan" | "line" | "spiral" | ...
  int    count        // 一次发射的子弹数
  float  speed        // 子弹速度 m/s
  float  interval     // 发射间隔 s
  float  spread_deg   // 扇形展开角度（fan 用）
  float  duration     // 持续时间 s（0 = 无限）
  // 扩展：角速度、加速度、颜色、伤害等
}
```
- 后端只下发"发射器参数 + 生成规则"，不下发每颗子弹的位置
- 前端按规则在本地重建所有子弹

### 2. Pattern 播放器
`BulletPatternPlayer.Update` 已实现 ring/fan：
```csharp
timer += Time.deltaTime;
if (timer < def.Interval) return;
timer = 0f;
for (int i = 0; i < def.Count; i++)
{
    float angle = def.Shape switch
    {
        "ring" => i * Mathf.PI * 2 / def.Count,
        "fan"  => (i - (def.Count-1)/2f) * (def.SpreadDeg * Deg2Rad / def.Count),
        _ => 0f
    };
    Vector3 dir = Quaternion.Euler(0, angle * Rad2Deg, 0) * transform.forward;
    BulletPool.Instance.Spawn(transform.position, dir, def.Speed);
}
```
- 需扩展支持 `line` / `spiral` 等 shape
- 发射器位置/朝向跟随父实体（怪/Boss）
- `duration` 到时间后停止发射并销毁发射器

### 3. 子弹对象池
`BulletPool` 核心：
- 预生成 N 颗子弹（如 200），禁用状态
- `Spawn(pos, dir, speed)` → 从池中取一颗，激活，设置速度
- 子弹寿命到/出界 → `Recycle()` 回收到池
- 池满时可扩展或丢弃最旧子弹

### 4. GPU Instancing
- 子弹使用相同 Material + Mesh，开启 `Enable GPU Instancing`
- 大量子弹（几百颗）时 DrawCall 降到 1
- 若子弹颜色不同（元素），用 MaterialPropertyBlock 逐实例设置颜色，不增加 DrawCall

### 5. 弹幕生命周期
```
服务器下发 S2C_SpawnPattern { pattern_id, emitter_entity_id, def }
  └─ 前端在 emitter_entity_id 位置创建 BulletPatternPlayer(def)
      └─ 按 interval 发射子弹
          └─ 子弹飞行（本地物理，不与服务器同步）
              ├─ 命中玩家 → 等服务器 S2C_HitApply 确认（见 M1 #7）
              └─ 寿命到/出界 → 回收到对象池
服务器下发 S2C_StopPattern { pattern_id }
  └─ 停止发射，已飞子弹继续到寿命结束
```

## 与后端对接
| 方向 | 消息 | 说明 |
|---|---|---|
| S→C | `S2C_SpawnPattern` | pattern_id、发射器实体 ID、pattern 定义 |
| S→C | `S2C_StopPattern` | 停止指定 pattern |
| 配置表 | `BulletPatternDef[]` | 开局下发的 pattern 配置表 |

## 关键技术点
- **不逐帧同步子弹**：只同步"规则"，子弹位置本地计算，节省带宽 100 倍
- **确定性**：pattern 规则必须确定，前后端看到的弹幕一致（速度/方向由规则唯一决定）
- **性能**：对象池 + GPU Instancing 是几百颗子弹流畅的前提
- **归属**：弹幕的归属（发射者）由服务器记录，用于结算统计（B2 #20）

## 验收标准
- [ ] 服务器下发 pattern 后，客户端能正确重建弹幕（ring/fan/line）
- [ ] 200+ 子弹同屏时帧率稳定 60fps
- [ ] 弹幕跟随发射器实体移动/旋转
- [ ] 停止 pattern 后，已发射子弹继续飞行到寿命结束
