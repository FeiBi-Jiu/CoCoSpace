## 核心纪律回顾

1. **上行只发意图不发结果**：发"我要开火"，不发"我打中了"
2. **不在客户端算任何影响胜负的数**：伤害/掉落/金币/仇恨全在服务器
3. **配置表从登录下发读，不硬编码**：元素表/技能表/pattern 表驱动
4. **冷路径 JSON，热路径 Protobuf**：地图/配置/结算走 JSON，快照/意图/事件走 Protobuf
