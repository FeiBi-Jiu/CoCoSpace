# M2 #17 · 鬼魂形态

## 所属阶段
M2 · 灰盒完整功能

## 任务目标
半透明无碰撞；拴绳范围圈可视化；搬运中物品显示在鬼魂身上。

## 前置依赖
- 前端：受击与死亡表现（M1 #13）
- 后端：鬼魂系统（B2 #15）

## 已有骨架
- `Assets/Scripts/Player/GhostForm.cs` — 鬼魂形态组件
- `Assets/Scripts/Player/DeathGhostTransition.cs` — 死亡→鬼魂过渡

## 实现步骤

### 1. 鬼魂视觉
- 半透明：`material.color.a = 0.4`，`RenderingMode = Fade`
- 无碰撞：`Collider.enabled = false`（服务器侧也无碰撞，保持一致）
- 可选：鬼魂模型换色（蓝白色调），与肉身区分

### 2. 拴绳范围圈
- 鬼魂被拴在最近的存活队友身上，半径可配（如 15m）
- 范围圈可视化：以队友为中心的半透明圆环（`LineRenderer` 或 `Projector`）
- 鬼魂超出范围 → 被拉回（服务器判定，客户端表现为瞬移回队友身边）
- 范围圈颜色：正常=绿色，接近边界=黄色，超出=红色

### 3. 跟随 buff
- 鬼魂在队友附近时给队友加 buff（如 +10% 伤害）
- buff 表现：队友身上有光环特效
- buff 数值由服务器应用，客户端只显示光环

### 4. 搬运判定
- 鬼魂可搬运特定物品（血瓶等标注"仅鬼魂可搬"的物品）
- 搬运中物品显示在鬼魂身上（跟随鬼魂移动）
- 搬运流程：
```
鬼魂靠近可搬物品 → 服务器判定可搬 → 物品跟随鬼魂
鬼魂将物品搬到目标位置 → 服务器放置物品
```
- 搬运物品的"仅鬼魂可搬"标签在掉落物生成时由服务器设置

### 5. 鬼魂 HUD
- 鬼魂玩家的 HUD 显示：
  - "鬼魂形态"标识
  - 跟随的队友
  - 拴绳剩余距离（距离边界还剩多少）
  - 可搬运物品高亮

## 与后端对接
| 方向 | 消息 | 说明 |
|---|---|---|
| S→C | 快照 `state = Ghost` | 实体处于鬼魂状态 |
| S→C | `S2C_GhostTether` | 拴绳：跟随的队友 entity_id + 半径 |
| S→C | `S2C_GhostTetherBreak` | 超出范围，拉回 |
| S→C | `S2C_ItemCarried` | 鬼魂搬运物品：item_id + carrier_id |
| S→C | `S2C_GhostBuff` | 鬼魂给队友加 buff |

## 关键技术点
- **鬼魂是服务器规则**：前端只做半透明+无碰撞的视觉，拴绳/搬运/buff 由服务器判定
- **碰撞一致性**：鬼魂无碰撞必须前后端一致，否则穿模/卡墙
- **拴绳可视化**：让玩家清楚知道能走多远，避免莫名被拉回
- **搬运显示**：搬运物品跟随鬼魂，用 `Transform.SetParent` 或每帧同步位置

## 验收标准

- [ ] 鬼魂附近的队友有 buff 光环
