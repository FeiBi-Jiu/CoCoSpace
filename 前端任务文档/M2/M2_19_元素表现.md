# M2 #19 · 元素表现

## 所属阶段
M2 · 灰盒完整功能

## 任务目标
火/水附着与组合特效，表驱动（登录下发的元素表 → 特效映射，不逐个硬编码）。

## 前置依赖
- 前端：配置表下发、弹幕系统（M1 #8）
- 后端：元素系统判定（B2 #16）

## 已有骨架
- `Assets/Scripts/Table/ElementTable.cs` — 元素表（附着特效 + 组合特效查表）
- `Assets/Scripts/Table/TableManager.cs` — 配置表管理

## 实现步骤

### 1. 元素表结构
```
ElementDef {
  uint32 element_id
  string name
  Color  color                 // 元素颜色
  string attach_fx_path        // 附着特效路径（Resources 下）
  Dictionary<uint, string> combo_fx  // 与其他元素组合的特效路径
}
```
- 开局通过冷路径（JSON）下发，`TableManager` 加载
- `ElementTable.Load` 已实现加载逻辑
- `ElementTable.GetAttachFx(elementId)` 查附着特效
- `ElementTable.GetComboFxPath(a, b)` 查组合特效

### 2. 附着表现
- 实体被元素攻击命中后，服务器下发 `S2C_ElementAttach { entity_id, element_id, duration }`
- 客户端在实体身上实例化附着特效（粒子），持续 `duration` 秒
- 附着期间实体染色（如着火=红色光晕）

### 3. 组合特效
- 两种元素附着在同一目标上 → 服务器判定组合 → 下发 `S2C_ElementCombo { entity_id, element_a, element_b }`
- 客户端查 `ElementTable.GetComboFxPath(a, b)`，在目标位置播放组合特效
- 组合特效示例：火+水=蒸汽、火+油=剧烈燃烧、水+雷=导电

### 4. 表驱动原则
- 所有元素相关特效路径都从元素表查，不硬编码
- 新增元素只需加配置表条目，不改代码
- 特效预制体放在 `Resources/` 下，按 `attach_fx_path` 加载

### 5. 元素颜色统一
- 据点染色（M1 #9）、附着特效、UI 图标都用元素表中的 `color`
- 保证火=红、水=蓝等视觉一致

## 与后端对接
| 方向 | 消息 | 说明 |
|---|---|---|
| 冷路径 | `ElementDef[]` | 元素配置表，开局下发 |
| S→C | `S2C_ElementAttach` | 元素附着：entity_id + element_id + 持续时间 |
| S→C | `S2C_ElementCombo` | 元素组合：entity_id + 两种元素 |

## 关键技术点
- **表驱动**：元素表下发后前端缓存，所有特效从表查，不硬编码
- **附着/组合判定在服务器**：客户端只负责播特效
- **Resources 加载**：特效预制体放 Resources 下，按路径加载
- **颜色统一**：元素颜色全游戏统一，从表取
