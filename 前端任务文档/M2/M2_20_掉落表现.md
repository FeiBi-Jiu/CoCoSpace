# M2 #20 · 掉落表现

## 所属阶段
M2 · 灰盒完整功能

## 任务目标
技能掉落高亮 + 10 秒腐烂倒计时环；金币/血瓶掉落（血瓶标注"仅鬼魂可搬"）。

## 前置依赖
- 前端：元素表现（M2 #19）、鬼魂形态（M2 #17）
- 后端：掉落 roll（B1 #12）、技能腐烂（B2 #18）

## 已有骨架
- `Assets/Scripts/World/DropView.cs` — 掉落物视图（腐烂倒计时环 + 鬼魂标签）

## 实现步骤

### 1. 掉落物类型
| 类型 | 表现 | 说明 |
|---|---|---|
| 技能掉落 | 高亮特效 + 腐烂倒计时环 | 10 秒消失，超时强化附近怪物 |
| 金币 | 金币图标 + 拾取自动吸入 | 触碰即拾取 |
| 血瓶 | 血瓶图标 + "仅鬼魂可搬"标签 | 只有鬼魂能搬运 |
| 道具 | 道具图标 | 普通拾取 |

### 2. 腐烂倒计时环
`DropView` 已实现：
```csharp
double despawnAt;
const double Lifetime = 10.0;
despawnAt = Time.timeAsDouble + Lifetime;
decayRing.fillAmount = Mathf.Clamp01((float)((despawnAt - Time.timeAsDouble) / Lifetime));
```
- 倒计时环围绕掉落物，10 秒内从满到空
- 时间到 → 掉落物消失，服务器强化附近怪物（B2 #18）
- 腐烂消失由服务器判定，客户端倒计时只是表现

### 3. 技能掉落高亮
- 技能掉落有特殊高亮特效（`highlightFx`）
- 颜色按技能属性（从元素表取色）
- 让玩家一眼看出是技能掉落

### 4. 血瓶"仅鬼魂可搬"
- 血瓶生成时服务器标记 `ghost_only = true`
- 客户端显示"仅鬼魂可搬"标签（`ghostOnlyTag`）
- 非鬼魂玩家靠近无交互提示
- 鬼魂玩家可搬运（见 M2 #17）

### 5. 拾取流程
```
服务器判定掉落 → S2C_DropSpawn { drop_id, type, pos, ghost_only }
  └─ 客户端实例化 DropView，设置类型表现
玩家靠近 → 服务器判定拾取 → S2C_DropPicked { drop_id, picker }
  └─ 客户端销毁 DropView，播放拾取特效
```
- 拾取判定在服务器，客户端不做拾取范围判定
- 金币可自动吸入（服务器判定范围内自动拾取）

## 与后端对接
| 方向 | 消息 | 说明 |
|---|---|---|
| S→C | `S2C_DropSpawn` | 掉落物生成：drop_id + 类型 + 位置 + ghost_only |
| S→C | `S2C_DropPicked` | 掉落物被拾取 |
| S→C | `S2C_DropDecayed` | 技能腐烂消失 + 附近怪物强化 |
| S→C | `S2C_DropCarried` | 鬼魂搬运物品 |

## 关键技术点
- **腐烂由服务器判**：10 秒倒计时是表现，实际消失由服务器控制
- **ghost_only 标签**：血瓶等物品只有鬼魂能搬，标签清晰可见
- **技能高亮**：技能掉落是高价值物品，必须醒目
- **拾取服务器权威**：客户端不做拾取判定，避免作弊
