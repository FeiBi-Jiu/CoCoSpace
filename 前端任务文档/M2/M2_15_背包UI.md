# M2 #15 · 背包 UI

## 所属阶段
M2 · 灰盒完整功能

## 任务目标
1 武器 + 2 技能 + 3 道具格；开背包引导进度条；受击打断表现。

## 前置依赖
- 前端：HUD（M1 #11）
- 后端：引导状态机（B2 #14）

## 已有骨架
- `Assets/Scripts/UI/BackpackUI.cs` — 背包 UI（长按 Tab 引导 + 受击打断）

## 实现步骤

### 1. 背包装备结构
```
Backpack {
  WeaponSlot   weapon       // 1 武器格
  SkillSlot[]  skills(2)    // 2 技能格
  ItemSlot[]   items(3)     // 3 道具格
}
```
- 装备数据由服务器下发（在快照中或单独 `S2C_BackpackUpdate`）
- 客户端只渲染，不做装备逻辑

### 2. 开启背包引导
`BackpackUI.Update` 已实现：
```csharp
if (Input.GetKey(KeyCode.Tab) && !opening)
{
    hold += Time.deltaTime / holdSeconds;   // holdSeconds = 0.4f
    progressBar.fillAmount = hold;
    if (hold >= 1f) { opening = true; Show(); }
}
if (Input.GetKeyUp(KeyCode.Tab)) hold = 0;
```
- 长按 Tab 0.4 秒打开背包（引导条）
- 松开则取消，进度归零
- 灰盒阶段引导在客户端本地判定，正式版由服务器判定（见下）

### 3. 受击打断
```csharp
public void OnLocalPlayerHurt()
{
    if (!opening) { hold = 0; progressBar.fillAmount = 0; }
}
```
- `GameRoot` 收到自己被命中的 `S2C_HitApply` 时调用 `OnLocalPlayerHurt`
- 引导中的进度归零，背包不会打开
- 已打开的背包不受影响（`!opening` 判断）

### 4. 引导状态机（服务器权威）
- 背包/祭坛复用同一引导状态机（B2 #14）
- 服务器维护引导进度，受击打断
- 客户端表现：进度条 + 受击打断动画
- 灰盒阶段可在客户端本地模拟（当前实现），正式版改为服务器下发 `S2C_InteractProgress`

### 5. 背包内容渲染
- 武器格：图标 + 名称
- 技能格 x2：图标 + CD 遮罩
- 道具格 x3：图标 + 数量
- 点击道具可使用（发送 `C2S_UseItem` 意图）

## 与后端对接
| 方向 | 消息 | 说明 |
|---|---|---|
| S→C | `S2C_BackpackUpdate` | 背包内容变化 |
| C→S | `C2S_UseItem` | 使用道具意图 |
| S→C | `S2C_InteractProgress` | 引导进度（服务器权威版） |
| S→C | `S2C_HitApply` | 受击 → 打断引导 |

## 关键技术点
- **引导状态机复用**：背包和祭坛用同一套"计时+受击打断"逻辑
- **受击打断由服务器判**：客户端只做表现，正式版引导进度由服务器下发
- **灰盒简化**：当前客户端本地判定引导进度，够用即可
- **装备不在客户端算**：装备效果由服务器应用，客户端只显示
