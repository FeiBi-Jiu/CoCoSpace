# M2 #22 · Boss1 表现

## 所属阶段
M2 · 灰盒完整功能

## 任务目标
两阶段 UI：蓄力条可视（协同破甲的前提）、破甲跳阶段演出。

## 前置依赖
- 前端：弹幕系统（M1 #8）、元素表现（M2 #19）
- 后端：Boss1 两阶段状态机（B2 #19）

## 已有骨架
- `Assets/Scripts/World/Boss1View.cs` — Boss1 视图

## 实现步骤

### 1. Boss 两阶段
| 阶段 | 特征 | 表现 |
|---|---|---|
| P1 | 普通攻击 + 挂油挂火易伤 | 正常 Boss 模型 |
| P2 | 蓄力 + 破甲窗口 | 蓄力条 + 狂暴特效 |

- 阶段切换由服务器判定（B2 #19）
- 客户端收到 `S2C_BossPhase { phase }` 后切换表现

### 2. 蓄力条可视（核心）
- Boss 进入蓄力状态时，服务器下发 `S2C_BossCharge { progress, break_window }`
- 客户端在 Boss 头顶显示蓄力条：
  - 蓄力进度（0~1）
  - 破甲窗口（一段高亮区域，表示在此区间攻击可破甲）
- 蓄力条是协同破甲的前提，全队必须能看到

### 3. 破甲跳阶段演出
- 玩家在破甲窗口内攻击 Boss → 服务器判定破甲 → 下发 `S2C_BossBreak`
- 客户端播放破甲演出：
  - Boss 护甲碎裂特效
  - Boss 进入短暂硬直
  - 屏幕震动
  - 跳阶段到 P2
- 若未在窗口内破甲 → Boss 释放蓄力大招 → 全队受击

### 4. 挂油挂火易伤
- Boss 被油/火附着时，显示附着特效（见 M2 #19）
- 易伤状态在 Boss 血条旁显示图标（油=黄色，火=橙色）
- 易伤数值由服务器应用，客户端只显示图标

### 5. Boss HUD
- Boss 血条（大，屏幕顶部）
- 当前阶段标识（P1/P2）
- 蓄力条（仅 P2 蓄力时显示）
- 易伤状态图标

## 与后端对接
| 方向 | 消息 | 说明 |
|---|---|---|
| S→C | `S2C_BossPhase` | 阶段切换：P1/P2 |
| S→C | `S2C_BossCharge` | 蓄力：progress + break_window |
| S→C | `S2C_BossBreak` | 破甲成功 |
| S→C | `S2C_BossUlt` | 蓄力大招释放 |
| S→C | `S2C_ElementAttach` | 挂油挂火易伤 |

## 关键技术点
- **蓄力条是协同核心**：全队必须能看到蓄力条和破甲窗口，才能协同破甲
- **破甲窗口可视**：用颜色区分"可破甲区间"和"普通区间"
- **阶段演出**：破甲跳阶段要有明显演出，给玩家正反馈
- **易伤可视化**：让玩家知道挂油/火有效，鼓励配合
