# M2 #18 · 弹幕交互表现

## 所属阶段
M2 · 灰盒完整功能

## 任务目标
反射/折射词条：队友弹幕转向；交汇第三效果特效触发。

## 前置依赖
- 前端：弹幕系统（M1 #8）
- 后端：弹幕交互判定、结算归属（B2 #20）

## 已有骨架
- `Assets/Scripts/Combat/BulletInteractionFx.cs` — 弹幕交互特效

## 实现步骤

### 1. 反射/折射词条
- 玩家技能带有"反射"或"折射"词条
- 队友弹幕经过该玩家时发生转向
- **判定在服务器**：服务器计算转向后的方向，下发 `S2C_BulletReflect`
- 客户端表现：子弹在反射点播放转向特效，然后按新方向飞行

```
服务器判定弹幕交汇 → S2C_BulletReflect { bullet_id, new_dir, reflect_by }
  └─ 客户端找到对应子弹 → 改变方向 → 播放反射特效
```

### 2. 交汇第三效果
- 两束不同属性的弹幕交汇时触发第三效果（如火+水=蒸汽爆炸）
- 服务器判定交汇，下发 `S2C_BulletCombo { pos, element_a, element_b }`
- 客户端在交汇位置播放组合特效（查表，见 M2 #19）

### 3. 特效触发
`BulletInteractionFx` 处理：
- 反射特效：在反射点播放粒子
- 交汇特效：在交汇点播放组合特效（从元素表查 `ComboFxPath`）
- 特效对象池化，避免频繁 Instantiate

### 4. 反射弹幕归属
- 反射后的弹幕归属 = 反弹者（B2 #20）
- 结算时伤害/击杀归反弹者
- 客户端无需处理归属，只做表现

### 5. 子弹标识
- 每颗子弹需要 `bullet_id`（服务器分配），用于反射/交汇时定位
- `BulletPool.Spawn` 时记录 `bullet_id`，服务器消息中带 `bullet_id` 定位客户端子弹

## 与后端对接
| 方向 | 消息 | 说明 |
|---|---|---|
| S→C | `S2C_BulletReflect` | 子弹被反射：bullet_id + 新方向 + 反弹者 |
| S→C | `S2C_BulletCombo` | 弹幕交汇：位置 + 两种元素 |
| 配置表 | 元素组合表 | 元素 A + 元素 B → 第三效果 |

## 关键技术点
- **判定在服务器**：反射/交汇的判定和数值全在服务器，客户端只做特效
- **bullet_id 定位**：服务器下发的反射消息必须能定位到客户端的具体子弹
- **组合效果查表**：从元素表查组合特效路径，不硬编码
- **归属由服务器记**：反射弹幕伤害归反弹者，客户端不参与结算

## 验收标准

- [ ] 反射点有特效
- [ ] 两束不同属性弹幕交汇时触发组合特效
